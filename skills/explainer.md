# Skill: explainer

## Purpose
A calm, thorough **90-second** explainer video for landing pages, documentation, and YouTube. Unlike `launch-video`, this format is for people who have already heard about the project and want to understand *what it actually does and why*. It is top-of-funnel education, not bottom-of-funnel conversion.

---

## Duration
**Exact: 90 seconds**

---

## Target Audience
Developers and technical decision-makers who discovered the project on GitHub, Hacker News, or through a friend. They are not yet convinced. They want proof that the tool solves a real problem *for them* before they invest time installing it.

---

## Core Principle
> "Buyer-first messaging. The product is not the hero — the user's *transformation* is."
> Don't open with your product name. Open with the viewer's pain. The product is the vehicle that takes them from Problem → Solution.

---

## Narrative Structure

| Timestamp | Beat | Voiceover Goal | Visual Goal |
|-----------|------|---------------|-------------|
| 0–15s | **The Problem** | Paint a vivid picture of the pain. Make the viewer feel *seen*. | Split-screen: old painful workflow on left, empty right side |
| 15–30s | **The Stakes** | Make the status quo feel costly. What happens if this keeps going? | Frustrated developer, time passing, opportunity cost visualized |
| 30–65s | **The Solution Walkthrough** | Introduce the product by name. Walk through 2–3 core workflow steps. Focus on outcomes, not features. | Product in action, each step clearly labeled on-screen |
| 65–78s | **The Proof** | One sentence of social proof or credibility. Open source? Trusted by N devs? Built on X tech? | GitHub stars, contributor count, or tech stack logos |
| 78–90s | **CTA** | Single, clear, low-friction next step. | URL, star button, Install command on-screen |

---

## Tone & Style
- **Voice:** Third-person narration, warm and authoritative — like a trusted senior engineer explaining to a junior
- **Energy:** Calm and measured. This is not a sales pitch. It is a clear explanation.
- **Pacing:** Medium cuts (3–6s per scene). Let the viewer absorb each step.
- **The "15-Second Rule":** Do NOT say the product name or show the logo in the first 15 seconds. Start with the user's pain.

### Feature → Consequence Translation
When writing the voiceover for features, always translate them:
| ❌ Feature-first (wrong) | ✅ Consequence-first (right) |
|---|---|
| "It has an AI-powered pipeline" | "So your demo video writes itself" |
| "It supports 5 output formats" | "Whether you're posting on Twitter or Product Hunt, it just works" |
| "It's open source under MIT" | "You own the code. Fork it, modify it, make it yours." |

---

## Visual Prompt Formula
> **[Camera Movement] + [Subject & Action] + [Environment] + [Lighting] + [Film Style]**

### Reusable Visual Prompt Library for This Skill

**Opening Problem Scene (0-15s):**
> "Split screen composition, left side shows a tired developer recording their third Loom take, frustrated, messy desk, harsh fluorescent light, right side intentionally empty. Cool, desaturated color grading, cinematic 16mm documentary aesthetic"

**Stakes Scene (15-30s):**
> "Time-lapse shot of a developer working late at night, clock on wall spinning rapidly, cold blue moonlight through window, stack of sticky notes, laptop glow on tired face, slow push-in, melancholic atmospheric tone, cinematic depth of field"

**Solution Step 1 — Repo Analysis:**
> "Close-up macro shot of a terminal window, 'reporeel init' command being typed, green text output appearing line by line, subtle scan line animation, dark office background, cool blue-green terminal glow, smooth dolly forward, technical documentation aesthetic"

**Solution Step 2 — AI Writing:**
> "Abstract digital visualization of text and code transforming into a structured script document, dark background with neon purple flowing data lines, elegant particle effects, smooth morph animation, cinematic sci-fi aesthetic, 4K clarity"

**Solution Step 3 — Video Output:**
> "Clean product mockup, a polished MP4 video file appearing on a dark desktop, satisfying dropdown animation, subtle glow around the file icon, minimalist dark mode environment, warm amber accent lighting, macro lens"

**CTA / End Card:**
> "Wide environmental shot of a clean minimal developer workspace, dual monitors showing the generated video playing and the project GitHub page, soft warm lamp light, organized and calm, satisfaction, end card text fades in smoothly"

---

## Negative Prompts
`stock footage, cheesy actors, suit and tie, corporate office, whiteboard, motivational poster, lens flare overuse, cartoon, animation, blurry, low resolution, watermark`

---

## Script Constraints
- Total voiceover word count: **~210 words** (90 seconds at 140 WPM)
- Max 3 features explained — if there are more, pick the 3 most transformative ones
- Each feature explanation: Problem → Action → Outcome (3-sentence max)
- End card must include: the CLI install command shown literally on screen
