# Skill: product-hunt

## Purpose
A fast-paced, high-energy 60-second promotional video specifically designed for Product Hunt launches, Twitter/X announcements, and HackerNews Show HN posts.

## Duration
Exact: 60 seconds

## Core Audience
Indie hackers, early adopters, developers, and product enthusiasts. They have short attention spans and want to know *exactly* what the product does within the first 5 seconds.

## Narrative Structure

### 1. The Hook (0-5s)
- Must grab attention immediately.
- Clearly state the painful problem the user is experiencing right now.
- *Example voiceover:* "You spend 4 hours making a demo video for every project launch. It sucks."

### 2. The Reveal / Solution (5-15s)
- Introduce the product name clearly.
- One-sentence value proposition.
- *Example voiceover:* "Meet RepoReel. Turn any GitHub repo into a stunning promotional video in one command."

### 3. The Demo / 'Aha' Moment (15-45s)
- Fast cuts showing the product in action.
- Highlight 2 to 3 absolute best features from the repo analysis.
- Focus on speed, ease of use, or magic moments.
- *Visual cue:* CLI typing, UI animations, before/after comparisons.

### 4. The Credibility Boost (45-50s)
- Why trust this? (e.g., open-source, local-first, specific tech stack, stars).

### 5. Call to Action (CTA) (50-60s)
- Clear, singular action for the viewer to take.
- *Example voiceover:* "RepoReel is open source. Try it today at reproreel.dev or star us on GitHub."

## Tone and Style
- **Pacing:** Fast, no fluff.
- **Tone:** Energetic, confident, developer-friendly (don't over-explain basic tech terms).
- **Voiceover Style:** Second-person perspective ("You"), conversational but punchy.

## Visual Prompts for AI Video Generation
- Focus on clean, modern, dark-mode aesthetics.
- Use neon accents (purple/blue).
- Avoid cluttered UI screenshots; prefer stylized, cinematic representations of coding/terminals.
