# Skill: release-notes

## Purpose
A polished **90-second** "What's New" release announcement video designed to be embedded at the top of GitHub Releases, changelogs, and posted to developer communities. This format celebrates contributors, builds loyalty among existing users, and converts passive watchers into active upgraders.

---

## Duration
**Exact: 90 seconds**

---

## Target Audience
**Existing users** who already know and trust the product. They are not being sold to — they are being celebrated and informed. The emotional tone should feel like a thank-you note combined with a product update.

---

## Core Principle
> "The version number is not the hero. The *solved problem* is."
> Don't open with "v2.0 is here." Open with the pain or request that drove this release: "You asked for faster builds. We listened."

---

## Narrative Structure

| Timestamp | Beat | Voiceover Goal | Visual Goal |
|-----------|------|---------------|-------------|
| 0–12s | **The "Why"** | Address the pain or request that caused this release. Acknowledge the community. | `git log` or GitHub Issues showing community requests, contributor avatars |
| 12–20s | **The Theme** | Name the version and the release theme in one sentence. | Clean version badge animation: "v2.0 — Built for Speed" |
| 20–55s | **Hero Feature Demo** | Walk through the most exciting new capability. Show it working. | Product in action — before/after split, or new UI being used |
| 55–70s | **Quick Hits** | Rapid-fire 2–3 other improvements or bug fixes. | Checklist animation, icons ticking off, fast cuts |
| 70–80s | **Contributor Shoutout** | Thank specific contributors by GitHub handle if possible. Build goodwill. | GitHub avatars, contributor graph, warm celebratory aesthetic |
| 80–90s | **CTA** | Tell them how to upgrade and where to find the full changelog. | `npm update` command on screen, link to GitHub Releases |

---

## Tone & Style
- **Voice:** Warm, grateful, collaborative — "we" not "I", "you" not "users"
- **Energy:** Celebratory but informative — think YouTube dev vlog, not corporate press release
- **Pacing:** Medium (3–5s per scene) — slower than launch video, viewer can absorb more
- **Forbidden phrases:** "excited to announce", "game-changing", "next-level", "industry-leading"
- **Required phrase style:** "You asked for X. Here it is." / "This one's for the people who..."

---

## Visual Prompt Formula
> **[Camera] + [Subject & Action] + [Environment] + [Lighting] + [Celebratory/Technical Tone]**

### Reusable Visual Prompt Library for This Skill

**Opening "The Why" Scene:**
> "Macro close-up of a GitHub issue tracker on a dark monitor, multiple 'feature request' labels visible, developer mouse hovering, warm desk lamp light, soft focus background showing busy open-plan developer office, empathetic storytelling aesthetic, slow push-in"

**Version Badge Animation:**
> "Clean dark background, large elegant version number 'v2.0' appearing with a smooth scale-up animation, subtle golden particle burst, minimalist design, satisfying reveal, sans-serif bold typography, dark tech aesthetic"

**Hero Feature Demo — Before:**
> "Side-by-side split screen, left labeled 'Before' in red, showing a slow cluttered workflow, cold blue light, stressed user, harsh environment"

**Hero Feature Demo — After:**
> "Right side labeled 'After' in green, same task completing instantly and cleanly, warm satisfied lighting, developer leaning back with arms open, clean minimal workspace, golden hour glow through window"

**Quick Hits Checklist:**
> "Animated checklist on dark background, three bullet points ticking off one by one with a satisfying green checkmark animation, clean monospace font, subtle glow effect, fast paced, satisfying rhythm"

**Contributor Shoutout:**
> "Warm celebration aesthetic, GitHub avatar grid appearing on screen, soft confetti particle effect, warm amber and gold lighting, community feel, inclusive joyful atmosphere, slow zoom"

**Upgrade CTA:**
> "Terminal screen in foreground, upgrade command being typed, progress bar completing smoothly, developer smiling at monitor in background, warm office lighting, clean and professional, text overlay with changelog URL"

---

## Negative Prompts
`corporate, boardroom, suit and tie, confetti explosion, fake excitement, stock footage presenter, teleprompter reading, cheap animation, generic background music, overly produced`

---

## Script Constraints
- Total voiceover word count: **~210 words** (90 seconds)
- Open with the community's voice: "You asked for..." or "The most requested feature..."
- If git log has contributor names: extract top 3 and mention them by GitHub handle
- End card must include: version number, upgrade command, full changelog link
- Background music: Warm, low-fi, slightly celebratory — NOT hype music
